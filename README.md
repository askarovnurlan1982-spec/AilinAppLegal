# Ailin privacy policy demo

A small, dependency-free privacy policy template designed for GitHub Pages.

## Customize

Before publishing, edit `index.html` and replace:

- `Ailin` and `Ailin, Inc.` with your product and company names
- `privacy@example.com` with your real privacy contact
- The sample postal address
- The effective date and any practices that do not accurately describe your app

This template is for demonstration purposes and is not legal advice.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your default branch and the `/ (root)` folder, then click **Save**.

GitHub will publish the page at the URL shown in the Pages settings.
